# SRE Agent 产品化路线与验收门槛

开源项目的能力对照、取舍和架构影响见 [OPEN_SOURCE_REFERENCE_ANALYSIS.md](OPEN_SOURCE_REFERENCE_ANALYSIS.md)。

## 产品定位

首个可收费版本定位为“有证据链、默认只读、变更需审批的 SRE Copilot”，面向已经使用 Kubernetes、Prometheus/Loki，但排障流程仍依赖少数资深工程师的研发团队。

核心付费价值不是聊天界面，而是：缩短告警到可执行结论的时间、沉淀团队排障知识、降低变更风险，并提供可审计的执行链路。

## 目标架构

```text
SSO / API Key
      |
API Gateway + RBAC + Tenant Boundary
      |
Conversation / Incident / Change Services
      |                  |
Read-only Connectors     Approval + Executor Queue
(Prom/Loki/K8s/CMDB)     (Argo/Jenkins/K8s)
      |                  |
PostgreSQL + Redis + Object Storage
      |
Metrics / Logs / Traces / Audit Export
```

## 分阶段发布门槛

### 当前实现状态（2026-07-20）

- M0 安全底座、M1 服务端变更状态机与持久化 Worker 已具备代码和回归测试。
- PostgreSQL 兼容层、容器、CI、健康门槛和备份/恢复手册已加入；目标托管环境的容量与故障演练尚未完成。
- 已实现单工作区的可撤销 API Key、RBAC、服务端套餐权限、月度额度、请求与模型成本计量。当前隔离边界是每客户独立部署，不等同于共享数据库多租户。
- 已实现付费试点价值证据记录、周/月聚合与 CSV 导出，可计算节省人时、建议采纳率、结果成功率、客户净价值及交付毛利；真实结论仍需连续试点数据验证。
- 已实现固定试用期限、订阅/宽限/停用状态、服务端 402 门禁和变更事件记录，并限制生产 Bootstrap Key 绕过计量；支付和开票仍未接入。
- 商业成熟仍以真实数据源、真实执行器、3 个设计合作客户和单位经济性验证为硬门槛。

### M0：安全只读试点

- 默认开启认证，至少提供 viewer/operator/admin 三档权限。
- 所有外部地址有 SSRF 防护和域名白名单。
- Token 不通过读取接口返回，生产密钥进入 Vault/KMS/Kubernetes Secret。
- 生产环境关闭真实写操作，只提供诊断、证据、建议和 dry-run。
- 对接至少一个真实 Prometheus、Loki、Kubernetes 集群。
- 具备租户隔离、审计导出、数据保留与删除策略。

### M1：测试环境受控变更

- 部署和回滚统一进入服务端变更请求状态机。
- 请求具备过期、防篡改、防重放、幂等键、并发锁和完整操作者记录。
- 接入一个真实执行器（优先 Argo CD 或企业现有发布平台）。
- 支持人工审批、超时、取消、重试和发布后健康验证。
- 所有失败路径均能给出确定状态，不允许“请求超时但后台未知是否执行”。

### M2：有限生产灰度

- PostgreSQL、Redis/任务队列、多实例部署、备份恢复和数据库迁移完备。
- SLO、告警、分布式追踪、结构化日志和容量基线完备。
- 完成安全评审、依赖扫描、渗透测试、负载测试和故障恢复演练。
- 仅向白名单服务开放变更，默认 dry-run，并要求 operator + approval。
- 真实事故中验证 MTTR、建议采纳率和变更成功率。

### M3：商业交付

- 支持多租户、配额、用量计量、套餐权限和账单数据导出。
- 提供企业 SSO、审计归档、私有化部署、升级回滚和 SLA。
- 形成标准化接入向导、实施清单、管理员手册、用户手册和支持流程。
- 至少完成 3 个设计合作客户试点，并有可复现的价值数据与付费转化证据。

## 商业模式假设（需要客户验证）

| 套餐 | 目标 | 计费假设 | 核心限制 |
|---|---|---|---|
| Trial | 设计合作与评估 | 限时/限额 | 1,000 请求/月、3 把工作区 Key、诊断与 dry-run |
| Starter | 小团队只读运维 | 团队基础费 | 10,000 请求/月、10 把 Key、无生产真实写 |
| Team | 中小研发团队 | 团队基础费 + 活跃服务数 | 100,000 请求/月、50 把 Key、受控生产变更 |
| Enterprise | 中大型企业 | 年费 + 实施服务 | 合同额度、Key 不限、受控生产变更；SSO/SLA/外部归档仍需交付 |

商业验证优先记录：每周活跃 SRE、接入服务数、成功诊断数、建议采纳率、节省的人时、MTTR 变化、试点转付费率、推理与基础设施单位成本。

## 产品完成定义

不能以“功能存在”作为成熟或可盈利的证明。最终验收需要同时满足：

1. 安全：身份、权限、密钥、网络出口、审计和数据隔离经验证。
2. 可靠：高可用、幂等、恢复、容量和可观测性经故障演练验证。
3. 有效：真实环境中诊断和变更流程达到预设准确率与成功率。
4. 可交付：客户能按标准流程完成安装、升级、接入和运维。
5. 可盈利：付费收入能够覆盖推理、托管、实施和支持成本，并有可重复获客路径。
